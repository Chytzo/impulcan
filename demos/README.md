# Demos comerciales

Propuestas privadas para validar el servicio de páginas web de Impulcan con comercios concretos.

Reglas:

- No publicar una demo como si fuera la web oficial del comercio.
- Usar solo datos públicos o confirmados por el propietario.
- No inventar horarios, precios, servicios, fotos ni reseñas.
- Antes de desplegar, pedir permiso y confirmar el canal de contacto.
- Registrar cada resultado en `datos/guias.db`.
